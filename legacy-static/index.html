How this wiki is built

  • Plain HTML pages sharing one stylesheet and one navigation script.
  • The sidebar and the “On this page” list are generated in the browser from a small manifest inside assets/wiki.js.
  • No build step, no server, no framework — it runs straight from the file system.
  • Upgrade path: if you later want full-text search, versioned docs or a hosted site, the same content can move into a static-site generator such as VitePress or MkDocs.

Cách wiki này được xây

  • Các trang HTML thuần dùng chung một stylesheet và một script điều hướng.
  • Menu bên trái và mục lục “Trong trang này” được sinh trong trình duyệt từ một manifest nhỏ trong assets/wiki.js.
  • Không build, không server, không framework — chạy trực tiếp từ hệ thống tệp.
  • Lối nâng cấp: nếu sau này cần tìm kiếm toàn văn, phiên bản hóa tài liệu hoặc đưa lên web, có thể chuyển nội dung sang static-site generator như VitePress hoặc MkDocs.
